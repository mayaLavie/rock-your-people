# יומן שינויים של פרויקט הקמפיין

## מטרת התיקייה
כאן מתועד כל שינוי שנעשה באתר במסגרת ההכנה לקמפיין, בצורה שמאפשרת לכל אדם להבין מה קרה ולהחזיר אחורה בלי לנחש.

## חלוקה לפי תחומי עבודה
- כל תחום עבודה כותב קובץ משלו בשם `changelog/<תחום>.md`, למשל `infra.md`, `pixel.md`, `design.md`.
- אסור לערוך קובץ של תחום אחר, כדי למנוע התנגשויות במיזוג.
- קובץ חדש נוצר בתחילת העבודה בתחום, והערכים מתווספים אליו מלמעלה (החדש ביותר ראשון).

## מבנה של ערך
כל ערך מתחיל בכותרת ברמה שנייה עם תאריך ושם קצר, ואחריה שלושה חלקים קבועים.

- מה השתנה: תיאור קצר ומדויק של השינוי, כולל רשימת הקבצים שנגעו בהם.
- למה: הסיבה לשינוי והבעיה שהוא פותר.
- איך מחזירים: הוראות מדויקות לביטול, והן חייבות לכלול את כל הפריטים הבאים:
  - נתיבי הקבצים שהשתנו.
  - שם משתנה הסביבה או הדגל, אם השינוי מוגן בדגל.
  - האש של הקומיט שיש להחזיר, בפקודה `git revert <hash>`.

## תבנית להעתקה
```
## 2026-01-01 שם קצר של השינוי

### מה השתנה
- ...

### למה
- ...

### איך מחזירים
- קבצים: ...
- משתנה סביבה: ... (או: אין)
- קומיט: `git revert <hash>`
```

## כללי כתיבה בעברית
- כל משפט, כל תבליט וכל כותרת מתחילים במילה בעברית, אף פעם לא במילה באנגלית או בקוד.
- מונח באנגלית או נתיב קובץ מופיע רק באמצע המשפט, אחרי מילה בעברית.
- הסיבה לכלל: משפט שנפתח באנגלית משבש את כיוון השורה כולה בתצוגה מימין לשמאל.
- האש של קומיט נכתב אחרי המילה "קומיט" ולא בתחילת שורה.

## הערה על האש של הקומיט הנוכחי
- ערך שמתועד באותו קומיט שבו הוא נכתב לא יכול להכיל את האש של עצמו.
- במקרה כזה מציינים את האש של הקומיט הקודם, או מעדכנים את הערך בקומיט עוקב.
