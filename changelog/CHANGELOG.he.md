# מפתח יומני השינויים של הקמפיין

## הסבר
- כל תחום עבודה מתועד בקובץ נפרד בתיקייה הזו, והרשימה למטה מפנה אליהם.
- כללי הכתיבה ותבנית הערך מופיעים בקובץ `README.md`.

## התחומים
- [תשתית](infra.md): הוספת Playwright, מדמה לרשת של Meta, סקריפט צילומי מסך ו-`npm run verify`, ומעבר לגופנים מקומיים כדי שהבנייה תעבוד בלי רשת.
- [מדידה](measurement.md): פיקסל של Meta ו-Conversions API בצד שרת עם הסכמת עוגיות, ייחוס utm ו-fbclid, מצב טופס ליד, אירועי ViewContent ו-Lead, ובדיקות אוטומטיות.
- [קופי וקריאות לפעולה](copy-cta.md): כפתורי קריאה לפעולה בהירו ובסוף הקטעים, איחוד האיות ל"מוזיקה", ניסוחים חדשים ודף הצהרת נגישות.
- [דפי נחיתה](landing-pages.md): ארבעה דפי נחיתה תחת `/lp/<מוצר>` עם תמונת שיתוף נפרדת לכל דף.
- [ביצועים ו-SEO](perf-seo.md): דחיסת מדיה, מטא-דאטה ותמונת שיתוף, מפת אתר ו-robots, נתוני JSON-LD ותיקוני lint.
- [אינטגרציה](integration.md): מיזוג הענפים, התאמת סימון המוצרים לשם הגלוי, תיקון טקסט הטופס, תמונת שיתוף מעודכנת ודוח רשת.
