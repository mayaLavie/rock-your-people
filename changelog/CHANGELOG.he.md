# מפתח יומני השינויים של הקמפיין

## הסבר
- כל תחום עבודה מתועד בקובץ נפרד בתיקייה הזו, והרשימה למטה מפנה אליהם.
- כללי הכתיבה ותבנית הערך מופיעים בקובץ `README.md`.

## התחומים
- [תשתית](infra.md): הוספת Playwright, מדמה לרשת של Meta, סקריפט צילומי מסך ו-`npm run verify`, ומעבר לגופנים מקומיים כדי שהבנייה תעבוד בלי רשת.
- [מדידה](measurement.md): פיקסל של Meta ו-Conversions API בצד שרת עם הסכמת עוגיות, ייחוס utm ו-fbclid, מצב טופס ליד, אירועי ViewContent ו-Lead, ובדיקות אוטומטיות.
- [קופי וקריאות לפעולה](copy-cta.md): כפתורי קריאה לפעולה בהירו ובסוף הקטעים, איחוד האיות ל"מוזיקה", ניסוחים חדשים ודף הצהרת נגישות.
- [דפי נחיתה](landing-pages.md): ארבעה דפי נחיתה תחת `/lp/<מוצר>` עם תמונת שיתוף נפרדת לכל דף.
- [ביצועים ו-SEO](perf-seo.md): דחיסת מדיה, מטא-דאטה ותמונת שיתוף, מפת אתר ו-robots, נתוני JSON-LD ותיקוני lint.
- [אינטגרציה](integration.md): מיזוג הענפים, התאמת סימון המוצרים לשם הגלוי, תיקון טקסט הטופס, תמונת שיתוף מעודכנת ודוח רשת, ובסבבים 2 ו-3 גם תיקוני אינטגרציה (ביקורות, פרטיות, ביצועי דפי נחיתה, מיקום החמור, לוגו ב-JSON-LD).

## סבב 2
- [הסכמה, פרטיות ומדידה](r2-privacy-measurement.md): פס עוגיות תחתון קומפקטי עם "אישור" ו"דחייה", עוגיית הסכמה חתומה, הקשחת הנתיבים `/api/meta/event` ו-`/api/lead`, כלל Lead מול Contact, שדה `cta_placement` ומדיניות פרטיות חדשה.
- [הירו, ביצועים וקופי](r2-hero-perf-copy.md): הירו חדש במובייל ובדסקטופ, טיזר החמור מושהה, סרטונים מקודדים מחדש, פוטר בעברית, כפתורי קריאה לפעולה לפי הקשר ודף נגישות מלא.
- [דפי נחיתה ושיתוף](r2-landing-sharing.md): קופי בלי כפילויות, תמונות הירו חדשות, שורת אמון, כותרות עמוד חדשות ותמונות שיתוף סטטיות לכל דף.

## סבב 3
- [מדידה, טפסים ופרטיות](r3-measurement-forms.md): רענון `_fbc` ב-fbclid חדש, הגבלת קצב לפי IP ומזהה הסכמה, נקודת בדיקת מצב `/api/meta/health`, פרטים נוספים מקופלים בטופס, שדה תאריך טקסטואלי, הודעה בחלון השיר ותוכן עניינים בדפי הפרטיות והנגישות.
- [מהירות](r3-speed.md): באנר, פיקסל ובר דביק נטענים אחרי load ו-idle, סרטון קטן לנייד, גופנים לטיניים מצומצמים, תמונות הירו חדשות לדפי הנחיתה וסמלי אתר קלים.
- [עמוד הבית וקופי](r3-home-copy.md): הירו בלי לוגו שני, תפריט בעברית, כותרת המלצות חדשה, "ערבי אחרי העבודה", שורת אמון לכל דף, כותרות קצרות ותמונות שיתוף מחודשות.
